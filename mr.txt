Title: Fix scalar Doppler correctness and validation

## Summary

This MR fixes output-length and dtype issues in the scalar wideband Doppler
transform and adds validation for invalid physical parameters and input shape.

Padding is now based on the effective integer ratio selected by the multistage
polyphase resampler rather than only the ideal Doppler factor. This prevents
long approaching-signal inputs from producing shortened output or zero-filled
tails. Padding retains the caller's dtype, effective unity-rate requests bypass
filtering, and final complex64 normalization avoids a copy when possible.

## Changes

- Add effective multistage-resampling rate calculation.
- Base scalar Doppler padding on the effective rate.
- Preserve input dtype during padding.
- Skip resampling for an effective 1:1 rate.
- Avoid unnecessary final complex64 copies.
- Validate propagation speed, velocity, and one-dimensional NumPy input.
- Add focused scalar Doppler regression tests.

## Test Plan

Run:

    pytest -q tests/transforms/test_functional.py

Coverage includes long-signal length and tail preservation, invalid physical
parameters, input dimensionality, padding dtype, unity-rate bypass, and
copy-free complex64 output normalization.
