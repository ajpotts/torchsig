Title: Add optional Doppler performance benchmarks

## Summary

This MR adds an optional pytest-benchmark suite for measuring the performance
of the Doppler optimization stack. It covers scalar calls, shared-rate batched
processing, and Doppler overhead during dataset generation.

The cases use deterministic complex64 inputs and seeded datasets. Each path is
warmed before timing, and benchmark results are checked for expected shape,
dtype, and finite values so performance measurements do not hide correctness
regressions.

## Changes

- Benchmark scalar Doppler across four signal lengths and three velocities.
- Compare `doppler_batch` with a scalar-loop baseline across batch sizes and
  signal lengths.
- Compare seeded dataset generation with and without Doppler.
- Keep implementation lookup tables so future candidates can be compared with
  the current implementation consistently.
- Keep all cases in the optional benchmark directory.

## Test Plan

Collect the benchmark cases without executing them:

    pytest --collect-only -q benchmarks/optional/benchmark_doppler.py

Run all Doppler benchmarks:

    pytest benchmarks/optional/benchmark_doppler.py --benchmark-only

Run one category when iterating:

    pytest benchmarks/optional/benchmark_doppler.py --benchmark-only \
        -k benchmark_doppler_batch

Useful comparisons are scalar performance by signal length and velocity,
`axis-batch` versus `scalar-loop`, and `dataset-with-doppler` versus
`dataset-baseline`. Benchmark output should be attached to the MR or recorded
in its discussion rather than committed as a result file.

## Scope

This is Part 5 of the Doppler optimization MR split and is stacked on Part 4.
It does not include implementation changes, committed benchmark results, or the
