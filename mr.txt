Title: Add batched Doppler support

## Summary

This MR adds a public `doppler_batch` API for applying one Doppler rate to a
two-dimensional batch of equal-length IQ signals.

The polyphase resampling operations now trim and validate results along the
final array axis. This lets a batch share the same filter setup and resampling
operation while preserving scalar-equivalent results, input geometry, and
complex64 output dtype.

## Changes

- Extend polyphase slicing and length checks to the final array axis.
- Add and export `doppler_batch`.
- Support arrays shaped `(batch, samples)` with a shared velocity.
- Preserve input batch shape and complex64 output dtype.
- Validate batch dimensionality and physical parameters.
- Test batch/scalar equivalence across approaching, stationary, and receding
  velocities.

## Test Plan

Run:

    pytest -q tests/transforms/test_functional.py tests/utils/test_dsp.py

Coverage includes scalar equivalence, output shape and dtype, invalid input
dimensionality, multiple velocities, and existing scalar/DSP regressions.

## Scope
