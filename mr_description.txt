Title: Preserve component associations in grouped dataset targets

Summary

- Allow tuple entries in target_labels to request an atomic group of metadata fields from each component signal.
- Return grouped values only when every requested field is available on the same component, preventing mismatched parallel target arrays.
- Support metadata from both built-in family grouping and arbitrary custom GroupingLabel configurations alongside detection annotations.
- Preserve the existing behavior for string target labels.
