Title: Document sampling-clock drift and jitter semantics

Problem

The public clock drift and jitter documentation still describes the previous
accumulated-random-drift model and does not define jitter units or independence.

Scope

- Document drift as a signed fixed sampling-rate offset.
- Document jitter as an independent per-sample displacement.
- State that jitter PPM is measured against one input-sample period.
- Update functional, transform-class, and DSP helper documentation.

Acceptance criteria

- Public documentation agrees with implemented drift and jitter behavior.
- Parameter units and sign conventions are explicit.
- Return dtype and validation errors are documented on the DSP helper.
- No executable behavior changes are included.

Out of scope

Additional clock models, API controls, and implementation changes.
