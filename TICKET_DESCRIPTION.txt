Title: Apply independent sampling-time jitter

Problem

Clock jitter currently accumulates into subsequent sampling positions and is
scaled in polyphase units rather than input-sample periods. Aperture jitter
should perturb each sampling instant independently.

Scope

- Draw one timing displacement for each output sample.
- Apply the displacement only to the current read position.
- Scale jitter by the polyphase up-rate so PPM refers to an input-sample
  period.
- Preserve the nominal output length.

Acceptance criteria

- Jitter does not accumulate into later nominal positions.
- Jitter does not change nominal output length.
- NumPy and Numba use the same input-period scaling.
- Output remains finite complex64 data.

Out of scope

Random-stream cleanup and public transform documentation.
