Title: Apply independent sampling-time jitter

Target branch: 3.0.0-dev

Summary

This MR makes clock jitter an independent displacement of each sampling instant
and defines its PPM scale relative to one input-sample period.

Changes

- Apply jitter only to the current read position.
- Exclude jitter from nominal-position advancement.
- Scale jitter by the polyphase up-rate.
- Test output-length invariance and finite complex64 output.

Verification

pytest -q tests/utils/test_sampling_clock_independent_jitter.py
