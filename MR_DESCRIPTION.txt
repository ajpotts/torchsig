## Summary

Vectorize the Python clock-resampler fallback and add direct Python/Numba performance coverage.

## Dependency and merge order

This branch targets `414-correct-clock-transform-documentation` and is merge-order step 7. See `tickets/drift_and_jitter/MERGE_ORDER.md`.

## Changes

- Vectorize polyphase filter-bank partitioning.
- Batch interpolation windows and phases in the Python position resampler.
- Preserve sub-phase interpolation and complex64 output.
- Remove redundant integer copies from clock wrappers.
- Add direct Python/Numba benchmarks and vectorization regression tests.

## Performance

The optional pure-Python `clock_jitter()` benchmark was run on the previous
commit and this branch with:

```text
python -m pytest benchmarks/optional/benchmark_clock_jitter_python.py \
  --benchmark-only --benchmark-min-rounds=1 --benchmark-max-time=0.2 -q
```

| Case | Previous mean | This branch mean | Speedup |
| --- | ---: | ---: | ---: |
| Integer positions | 25.2126 ms | 1.4940 ms | 16.9x |
| Interpolated positions | 37.8729 ms | 1.5556 ms | 24.3x |

On this system, vectorization reduced the additional cost of interpolated
positions from about 50% over integer positions to about 4%.
