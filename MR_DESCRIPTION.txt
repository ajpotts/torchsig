Title: Define drift as a fixed sampling-rate offset

Target branch: 3.0.0-dev

Summary

This MR changes `drift_ppm` from accumulated random drift to a signed, fixed
sampling-rate offset in both sampling-clock implementations.

Changes

- Advance nominal positions using the validated drift-adjusted increment.
- Size initial output storage for positive and negative rate offsets.
- Remove random-number consumption from drift-only processing.
- Test positive, zero, and negative drift in NumPy and Numba.

Verification

pytest -q tests/utils/test_sampling_clock_fixed_drift.py
