Title: Harden sampling-clock output capacity

Target branch: 3.0.0-dev

Summary

This MR adds explicit output bounds and controlled capacity growth to the NumPy
and Numba sampling-clock implementations.

Changes

- Check capacity before every output write.
- Grow NumPy output storage geometrically within a defensive limit.
- Grow Numba wrapper output and random-value capacity together.
- Raise a clear error when the defensive capacity is exhausted.
- Add direct coverage for an undersized compiled-kernel buffer.

Verification
