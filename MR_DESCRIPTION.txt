## Summary

Replace symmetric zero padding of short sampling-clock output with alignment-aware edge extension.

## Dependency and merge order

This branch targets `414-align-zero-impairment-output` and is merge-order step 4. See `tickets/drift_and_jitter/MERGE_ORDER.md`.

## Changes

- Extend the first or last valid sample when aligned output falls outside the generated range.
- Use edge extension instead of inserting zeros for legacy length-only normalization.
- Preserve complex64 dtype and return zeros only when the resampler produced no samples.
- Add short-output and aligned-tail boundary tests.

## Testing

- Zero, one, and multiple missing-output boundary cases
- Sampling-clock output length and dtype tests
- Existing clock transform tests
