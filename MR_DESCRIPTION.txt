Title: Add time-varying sampling-clock drift models

Target branch: 165-clock-initial-phase
Ultimate target: 3.0.0-dev

Summary

This MR replaces the former constant sampling-clock offset with selectable
time-varying drift trajectories. It builds on the corrected resampler from MR 1
and keeps the NumPy and Numba implementations deterministic and equivalent.

Changes

- Add drift_model values linear, random_walk, and filtered_noise.
- Generate signed linear ramps between initial and final PPM error.
- Generate seeded random-walk and correlated filtered-noise rate errors.
- Add initial sampling phase and initial drift controls.
- Integrate rate-error trajectories into absolute sampling positions.
- Validate model selection, parameters, and positive position increments.
- Add analytical trajectory, reproducibility, public-transform, and parity
  tests.

Review guidance

The resampler mechanics belong to MR 1. This review should focus on trajectory
definitions, integration into sampling position, parameter validation, and
seeded behavior. The trajectory tests use small explicit sequences so the
expected behavior can be checked without detailed polyphase-filter knowledge.
