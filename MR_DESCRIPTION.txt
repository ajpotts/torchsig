Title: Add initial sampling phase and ClockDrift controls

Target branch: 165-clock-engine-hardening
Ultimate target: 3.0.0-dev

Summary

This MR exposes initial sampling phase consistently through the clock engine,
functional API, and ClockDrift transform. It also adds signed drift ranges and
explicit linear or logarithmic range sampling.

Changes

- Add initial_phase to NumPy and Numba sampling-clock entry points.
- Add initial_phase to functional clock_drift and ClockDrift.
- Validate scalar and range phase values.
- Change the default drift range to signed values.
- Add drift_sampling values linear and log10.
- Add public API, validation, and parity tests.

Review guidance

The underlying fixed-offset and independent-jitter semantics belong to MR 1,
and the edge-case contract belongs to MR 2. This review should focus on phase
units, range validation, and public parameter propagation.
