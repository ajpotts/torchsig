Title: Align seeded NumPy and Numba sampling-clock streams

Target branch: 3.0.0-dev

Summary

This MR gives the NumPy and Numba sampling-clock paths one equivalent seeded
jitter stream and adds explicit combined-impairment parity coverage.

Changes

- Replace the interleaved compatibility pool with one float64 jitter array.
- Pass one jitter value per output sample to the compiled kernel.
- Preserve seeded values during capacity growth.
- Test combined drift/jitter parity and reproducibility.
