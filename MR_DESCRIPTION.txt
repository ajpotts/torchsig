## Summary

Expose configurable sampling-clock jitter models through the public functional and transform APIs.

## Dependency and merge order

This branch targets `414-configurable-jitter-models` and is merge-order step 9. See `tickets/drift_and_jitter/MERGE_ORDER.md`.

## Changes

- Add `jitter_model` and `jitter_alpha` to `clock_jitter()`.
- Add the same configuration to `ClockJitter`.
- Validate model names and AR(1) alpha in the transform constructor.
- Preserve independent jitter as the public default.
- Pass configuration through to both Python and Numba-backed clock engines.

## Testing

- Default public configuration
- Functional pass-through for independent, period, and AR(1) models
- Transform-class pass-through
- Invalid model and alpha validation
- Existing sampling-clock statistical and parity suites
